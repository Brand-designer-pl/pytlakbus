# PytlakBus — landing (propozycja)

Strona przewozów osób PytlakBus: scena scrollowa z wideo, flota z widokami specyfikacji, rezerwacja i podstrona Kontakt.

- Podgląd: https://brand-designer-pl.github.io/pytlakbus/
- Stack: Next.js 16 (statyczny eksport), React 19, GSAP (ScrollTrigger, SplitText).
- Lokalnie: `npm install`, `npm run dev` → http://localhost:3107
- Publikacja: każdy push na `main` buduje i publikuje stronę (GitHub Actions → Pages).

Do uzupełnienia przez klienta: dane kontaktowe (`contact` w `src/content.ts`) oraz miejsce wysyłki formularzy.
